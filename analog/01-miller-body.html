ANALOG IC / CHAPTER 01

两个寄生效应

密勒效应把一个 5 fF 的电容变成 300 fF，背栅效应让阈值电压跟着源极电位走。 这两个参数都不在原理图上，也没有人设计它们，但都直接决定电路能不能用。

Miller Cascode Body Effect γ
01

5 fF 的电容，26 kHz 的带宽

一级共源放大器，参数给全：gm = 1 mA/V， RD = 50 kΩ，电压增益 Av ≈ −gmRD = −50。 信号源内阻 Rs = 20 kΩ， 管子本身的电容 Cgs = 45 fF， 栅漏交叠电容 Cgd = 5 fF。

只算 Cgs 的话，输入端是一个 RC 低通：

fp = 1 / (2πRsCgs) = 1 / (2π × 20 kΩ × 45 fF) ≈ 177 kHz

但 Cgd 不是接地的。它跨在栅极和漏极之间， 而漏极电压是栅极的 −50 倍。两端电压差不是 vi，而是 vi − vo = vi(1 + 50) = 51vi。 同一个电容，充放电电流大了 51 倍。

从输入端看，它等效成 5 fF × 51 = 255 fF。加上原来的 Cgs：

Cin = Cgs + Cgd(1 + |Av|) = 45 + 5 × 51 = 300 fF 零点没有变，极点变成 1/(2π × 20 kΩ × 300 fF) ≈ 26.5 kHz，比原来低了 6.7 倍。

一个 5 fF 的电容，把带宽从 177 kHz 拉到 26.5 kHz。这就是密勒效应： 跨接在反相增益两端的电容，在输入端会被放大 (1 + |A|) 倍。

共源级。Cgs 一端接地，只算一次； Cgd 跨在输入输出之间，被放大 51 倍。
02

米勒定理：把跨接阻抗拆成两个接地阻抗

上面那个 51 倍不是巧合。设节点 1、2 之间接一个阻抗 Z，节点 2 的电压是节点 1 的 −A 倍（A > 0，反相放大）。从节点 1 流出的电流：

i1 = (v1 − v2) / Z = v1(1 + A) / Z

所以从节点 1 看进去的等效阻抗是 Z/(1+A)。 对电容 Z = 1/(jωC)，等效电容就是 C(1+A)。同一个推导换到节点 2，得到 Z/(1+1/A)，A 大时约等于 Z：

Cin = C(1 + A)      Cout = C(1 + 1/A) ≈ C 密勒效应是单向的：输入端被放大，输出端几乎不变。所以它只影响输入极点。
左：跨接的 Cgd。右：等效成输入端的 C(1+A) 和输出端的 C(1+1/A)。

用它的前提，三条缺一不可：

1. 增益 A 是已知的、并且在这一段频率上基本不变。A 本身随频率掉，密勒等效也就跟着变。
2. 电路是单向的，信号只从输入走到输出。强反馈里这个等效会失效。
3. 它只用来求端口等效阻抗。拿它算噪声、算功耗、算电容上的电荷，都是错的。

03

主极点：增益和带宽不能同时要

把密勒放大后的电容代进极点表达式，输入极点是：

fp1 = 1 / { 2πRs [ Cgs + Cgd(1 + gm(RD ∥ ro)) ] }

输出端也有一个极点， fp2 = 1/(2π(RD∥ro)(Cdb + Cgd(1+1/A)))。 但 RD 通常只有几十 kΩ，比 Rs 小得多，所以 fp2 远高于 fp1。输入极点就是主极点， 它一个人决定了 −3 dB 带宽。

把增益和带宽乘起来，会得到一个不太舒服的结论：

Av · fp = Av / { 2πRs Cgd(1 + Av) } ≈ 1 / (2πRs Cgd) A 消掉了。把增益做大一倍，带宽就窄一半，乘积不变。
同一级放大器。灰色是只算 Cgs 的理想情况， 靛蓝是实际带 Cgd 的情况。低频增益一样，拐点差了 6.7 倍。
04

对策：让跨接电容看到低阻节点

密勒放大倍数等于 1 + |A|，A 是跨接电容两端的电压增益。 如果能让这个增益接近 0，放大倍数就退化成 1。共源共栅（cascode）做的就是这件事。

在输入管 M1 的漏极上再串一个共栅管 M2，栅极接固定偏置 VB。M1 漏极看到的负载不再是 RD，而是 M2 源极看进去的阻抗， 约 1/gm2。于是这个节点的增益是 −gm1/gm2 ≈ −1。

Cin = Cgs1 + Cgd1(1 + 1) ≈ Cgs1 + 2Cgd1 对比原来的 Cgs1 + 51Cgd1，输入电容基本只剩 Cgs1。

代价是实打实的，四条：

1. 摆幅。输出最高只能到 VDD − 2Vov，多堆一个管子就少一个过驱动电压。
2. 偏置。多一条 VB，而且它必须保证 M2 一直在饱和区。
3. 新极点。M1 漏极那个节点阻抗约 1/gm2， 和 Cgd1 + Cdb1 组成一个新极点。通常频率很高， 但增益做大之后它会掉下来，成为新的瓶颈。
4. 噪声。M2 会贡献一份噪声，折算到输入大概增加 10%–30%。

共源共栅。Cgd1 跨在栅极和 X 之间，而 X 的阻抗约 1/gm2，节点增益只有约 −1，密勒放大基本消失。

另外两种做法也常用：差分对把输入管的漏极接到另一个管子的源极，效果类似； 中和电容（neutralization）是在栅漏之间再并一个反相驱动的电容，把 Cgd 的电流抵消掉，只在窄带里有意义。

05

源极不接地时，阈值开始漂

NMOS 的衬底通常接全芯片最低电位。只要源极和衬底同电位（ VSB = 0），前面所有公式里的 VTH 就是一个常数。

但源极并不总是接地：源跟随器的输出就取在源极上；cascode 的下管源极接在中间节点； 传输门里信号从源极进出。这些情况下 VSB > 0，源-衬底 PN 结被反偏， 耗尽层变宽。栅极要先把这层多出来的电荷填掉，才能形成反型层—— 同样的栅压，沟道更薄，阈值更高。

VTH = VTH0 + γ( √(2φF + VSB) − √(2φF) ) VTH0 是 VSB=0 时的阈值，2φF 是表面强反型所需的表面势，γ 是体效应系数。
同一只管子，源极电位抬高后源-衬底结反偏加深，耗尽层向衬底扩张， 阈值电压升高。图中虚线圈出的就是扩张的部分。
06

γ 有多大：一组实际数字

体效应系数 γ 由工艺决定，和掺杂浓度成正比、和栅氧厚度成反比：

γ = √(2qεsi NA) / Cox q 是电子电荷，εsi 是硅介电常数，NA 是衬底掺杂，Cox 是单位面积栅氧电容。

取一个 0.18 μm 级别的工艺：tox = 4 nm， Cox = εox/tox ≈ 0.86 μF/cm²； 衬底掺杂 NA = 1017 cm−3， 算得 2φF ≈ 0.82 V， γ ≈ 0.21 V1/2，零偏阈值 VTH0 = 0.45 V。

gmb = γgm / (2√(2φF + VSB)) = ηgm η 一般在 0.05–0.2 之间，VSB 越大 η 越小——因为 √ 里那一项在变大。

07

三个后果

源跟随器

源极是输出，体效应直接串进增益： Av = gm/(gm + gmb + 1/ro) ≈ 1/(1+η)。 η = 0.117 时只有 0.895。所以源跟随器的增益永远小于 1， 而且输出摆得越高，VSB 越大、η 越小，增益还会跟着变——这就是它的非线性来源。

传输门 / 开关

导通电阻 Ron = 1/[μnCox(W/L)(VGS − VTH)]。 信号电平升高，源极电位跟着升高，VSB 变大、VTH 变大， Ron 随之变大。单管开关的电阻随信号变化，就是失真。 所以要用 NMOS 与 PMOS 并联的传输门——两者的体效应方向相反，Ron 互相补偿。

堆叠管 / cascode

越靠上的管子，源极电位越高，体效应越重。结果是需要更大的栅偏置才能维持同样的电流， 输出摆幅又被吃掉一截。设计 cascode 的偏置时，第二个管子的 VTH 必须按它的实际 VSB 算，不能直接套 0.45 V。

对策

最直接的办法是让源极和衬底短接：给每只 NMOS 单独一个 P 阱（或者深 N 阱里的独立岛）， 衬底接到自己的源极上。代价是面积和阱电容。再往上走是 SOI， 衬底完全隔离，体效应基本消失，但 wafer 贵、模型也复杂。

传输门：NMOS 与 PMOS 并联，Ron 互补
08

小结：两个效应对照

两者都来自"不该有的那一端电压差"。密勒效应看的是电容两端的电压比， 背栅效应看的是源极和衬底的电位差。共同点是：原理图上都看不见，但都必须在设计时算进去。
