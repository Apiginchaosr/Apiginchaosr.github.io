让网络认出
一个手写数字

这一章只做一件事：把一个 28×28 的像素矩阵，一步步变成「是 7 的概率为 96%」。 中间每一步都能看见 —— 逐像素扫描、加权求和、非线性、层间传递、softmax、反向传播。

01

机器没有「看见」，它只拿到一串数

你看到下图里的 7，会立刻想到"拐角、一横、一撇"。但计算机拿到的只是 28 × 28 = 784 个 0 到 1 之间的灰度值 —— 一片数字。它不知道什么是笔画， 更不知道什么是"七"。所谓识别，本质上是寻找一种映射：

f : ℝ784 → ℝ10 输入 784 维像素向量，输出 10 个类别的得分（数字 0~9）

把鼠标放到网格上，可以看到每个格子真实的坐标和灰度；点「展平」按钮， 它会被按行优先的顺序拉成一条长 784 的向量 —— 这正是网络真正的输入形态。

这 784 个数里，绝大部分是背景，真正的信息集中在几十个亮点上 —— 但网络一开始并不知道哪些重要。 所以每个输入都要配一个权重，让网络自己学出"该看哪里"。

02

一个神经元：一次加权打分

拉出网络里的任意一个神经元，它做的事简单到只有两步 —— 先加权求和，再过一个非线性。

z = ∑i wixi + b
a = ReLU(z) = max(0, z) wᵢ 是权重（这个输入有多重要），b 是偏置（整体阈值），a 是激活值（这个神经元"有多兴奋"）

把它理解成打分：权重像一个模板，输入和模板越像，点积越大。下面四个输入固定，拖动权重看输出怎么变：

注意 ReLU 的作用：z 是负的就归零。这意味着神经元可以"不发言" —— 大部分神经元处于关闭状态，网络因此是稀疏激活的。如果不加这个函数，z 直接往后传，会发生什么？下一节。

03

为什么必须有非线性

假设没有激活函数，两层网络是这样叠加的：

a(2) = W(2)(W(1)x + b(1)) + b(2) = (W(2)W(1))x + b' 两个矩阵相乘还是一个矩阵 —— 一百层也只能等价于一层，永远只能画一条直线

所以每层之间必须插一个逐元素的非线性函数。最常用的是 ReLU（简单、梯度不衰减）， 经典的 sigmoid 和 tanh 现在主要出现在门控结构里。

Activation functions

ReLU 的导数只有两个值：z > 0 时是 1，z < 0 时是 0。这让梯度在反向传播时 不会因为层层相乘而迅速消失（sigmoid 的导数最大只有 0.25，五层之后就是 0.001 量级）。

04

把它们堆起来：784 → 128 → 64 → 10

单个神经元只能画一条线，堆成层之后就能组合出任意复杂的形状。这里的结构是一个典型的 多层感知机（MLP）：两个隐藏层，最后接 10 个输出节点，分别对应数字 0~9。

三层各自在做什么

  • 第一层（784 → 128）：从像素里提取最基础的"笔画片段"——某处的一段横、一段竖、一个角。128 个神经元 = 128 种不同的局部模板。
  • 第二层（128 → 64）：把片段组合成结构。"左上角一撇 + 中间一横"开始有数字的意义。
  • 输出层（64 → 10）：把结构映射到类别打分。注意这里输出的是打分（logit），不是概率，还要过 softmax。
关于本演示 浏览器里没跑训练，权重按可解释的方式设定，才能毫秒级给出合理结果。真实的 MNIST 模型 是经过反向传播（第 06 节）在上万张图上磨出来的，但前向传播的形状和这里完全一致。
05

Softmax：把打分变成概率

输出层的 10 个 logit 可以是任意实数，比如 [-3.2, 1.1, 8.7, …]。 要做分类，得把它们压成加起来等于 1 的正数：

pi = ezᵢ / ∑j ezⱼ 先指数放大差距，再归一化 —— 大者更大，小者趋近 0

关键是那个 e 的指数：logit 相差 2，概率比就是 e² ≈ 7.4 倍。所以 softmax 不是"平均分配"， 而是放大赢家。拖下面三个 logit 试试，再调温度看看分布怎么变化：

温度 T 写在指数里变成 e^(z/T)：T 越小分布越尖（更自信、更极端）， T 越大越平（更犹豫）。模型蒸馏里就是用大模型的高温输出当"软标签"来教小模型。

06

它怎么学会的：损失与反向传播

上面的权重是给定的。真实训练里，权重一开始是随机的，网络输出一团糟。要让它变好， 就需要一个衡量"错得多离谱"的指标 —— 交叉熵：

L = −log(py) p_y 是网络给"正确答案"分配的概率。预测对了且自信 → L≈0；自信地错了 → L 爆炸

拖动滑块，看看正确答案的概率和损失的关系（注意曲线在低概率端有多陡）：

Cross-entropyp = 0.96 → L = 0.041
p_y 0.960

梯度下降：往低处长

有了损失，就能算出每个权重对损失的责任 —— 这就是梯度 ∂L/∂w。反向传播本质上是链式法则的高效实现： 从输出往回，一层层把误差分摊下去，然后所有参数朝梯度的反方向挪一小步。

w ← w − η · ∂L/∂w η 是学习率。太大震荡发散，太小爬得慢 —— 这是调参的第一个坎
Training loss · 12 epochs

曲线前几个 epoch 掉得很快，后面越来越平 —— 因为一开始几乎所有模板都是错的， 修正空间巨大；接近最优后，梯度本身变小了。这条曲线的形状几乎是深度学习训练的"指纹"。

容易踩的坑 梯度消失：深层网络 + sigmoid，前面的层几乎收不到信号 → 用 ReLU、残差连接、归一化解决。
过拟合：训练集损失一直降，验证集开始涨 → 正则化、Dropout、早停。
07

全景回顾

把整条链路串起来，一次识别就是这么走完的：

1
读入图像
28×28 灰度图 → 归一化到 [0,1] → 展平成 784 维向量 x
2
第一层：线性 + ReLU
a¹ = ReLU(W¹x + b¹)，形状 128，从像素里抽局部特征
3
第二层：组合特征
a² = ReLU(W²a¹ + b²)，形状 64，把笔画拼成结构
4
输出层：打分
z = W³a² + b³，形状 10，对应 0~9 的未归一化分数
5
Softmax：变成概率
p = softmax(z)，取 argmax 得到预测结果
6
训练时：算损失、反向传播
L = −log p_y → 链式法则求梯度 → w ← w − η·∂L/∂w，重复成千上万次

公式速查

线性层z = W·x + b   (m×n · n×1 → m×1)
激活ReLU(z) = max(0, z)
输出概率pi = ezi ⁄ Σj ezj
交叉熵L = −Σi yi·log(pi)
参数更新w ← w − η·∂L/∂w
参数量784×128 + 128×64 + 64×10 ≈ 109,000
