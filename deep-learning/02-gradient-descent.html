模型学没学会，只看一个数——损失。梯度下降就是「每一步都朝让损失变小的方向挪一点」。 这一章把导数、梯度、学习率和随机性拆开，并且让小球真的在曲面上滚一遍。

01

蒙着眼，怎么下山？

想象你被丢在一片山谷的某个位置，眼睛被蒙住，只能感受脚下的坡度。 要走到谷底，最朴素的办法是：用脚试探哪个方向最陡，朝下坡迈一步，停下来重新感受，再迈一步。

这就是梯度下降。它并不「知道」谷底在哪，只依赖当前位置的局部信息—— 而正是这种只看脚下、却能反复逼近最优的性质，让它成为几乎所有深度学习训练的底座。

w(t+1) = w(t) − η · ∇L(w(t)) 三个要素：起点 w⁽⁰⁾（初始化）、方向 −∇L（最陡下坡）、步长 η（学习率）
Descent, conceptuallyFig. 01

注意图上每一次迈步都比上一次更短：越靠近谷底，坡度越缓，同样的学习率走出来的一步自然越小。 这是梯度下降自带的性质——它会自动减速。

02

导数：一维的坡度

在一维情况下，「梯度」就是导数。导数的几何意义是曲线在某点的切线斜率， 它同时告诉你两件事：往哪边走（符号）和有多陡（大小）。

  • f'(w) > 0 — 函数正在上升，应该往左走（减小 w）
  • f'(w) < 0 — 函数正在下降，应该往右走（增大 w）
  • f'(w) = 0 — 脚下是平的，可能已经到极值点了

更新式 w ← w − η·f'(w) 里那个减号就是在自动处理方向： 导数为正时减去正数、w 变小；导数为负时减去负数、w 变大。两种情况下都在下坡。

Tangent line拖动曲线上的点
w = -2.40
L(w) = 0.00
斜率 L'(w) = 0.00
→ 向右走
03

梯度：把导数推广到多维

模型参数通常有几十万个，损失是这些参数的高维函数。把每个方向上的偏导拼起来，就是梯度：

∇L = [ ∂L/∂w1,  ∂L/∂w2,  …,  ∂L/∂wn ] 一个和参数同维的向量，每个分量表示「只往这个方向动一点，损失会变多快」

梯度有三个关键性质，第三个最常被忽略：

  1. 它指向函数增长最快的方向；
  2. 它的长度等于那个方向上的变化率；
  3. 它垂直于等高线——等高线上函数值不变，所以沿等高线移动损失不变，最陡方向必然与之垂直。

所以 −∇L 是下降最快的方向，而「最快」是局部意义上的：它只保证这一步降得最多， 不保证能一路走到全局最优。

Contour & gradient移动鼠标看箭头
L(w₁,w₂) = w₁² + 4w₂²
∇L = (0.0, 0.0)
箭头方向 = −∇L（下降方向）

注意等高线是扁的：w₂ 方向的系数是 4，同样的位移带来的损失变化更大， 所以这个方向更陡、梯度分量也更大。这种各方向陡峭程度不一致的情况，正是后面「震荡」的根源。

05

学习率：最该先调的参数

同一条曲线、同一个起点，只改学习率，结局完全不同。下面三条轨迹并排跑：

Three fates
η = 0.04 η = 0.30 η = 1.06
三种命运：爬得太慢 / 快速收敛 / 震荡发散

η 太小的代价是时间；太大则可能让参数直接飞出可行域。 实践中常用的做法是先做一次 learning rate range test（从小到大扫一遍，看 loss 在哪开始上升）， 或者干脆用 Adam 这类自适应方法——它给每个参数单独维护一个有效步长。

06

用多少数据算一次梯度

真实训练里，损失是整个数据集上的平均。每走一步都算一遍全量梯度太贵， 于是有了三种取法：

  • 批量梯度下降（BGD）：用全部样本算梯度。方向最准，一步顶一步，但单步极慢。
  • 随机梯度下降（SGD）：每次只用一个样本。快，但梯度噪声大，路径抖得厉害。
  • 小批量（mini-batch）：每次 32～512 个样本。噪声适中，还能吃满 GPU 并行——这是实际默认选项。
Batch size vs. path
等高线：w₁² + 4w₂² = c
全量梯度：路径平滑，直指谷底

抖动的路径看起来"不优雅"，但噪声反而有帮助：它能把你从浅的局部极小或鞍点附近推出去。 这也解释了为什么小批量往往比全量梯度泛化更好。

07

走不动的时候

梯度下降失效的方式就那么几种，认出来就能对症下药。

症状损失卡住不降

可能停在局部极小或鞍点：梯度接近 0，但并不是最优。高维空间里鞍点远多于局部极小。

对策动量 / 随机噪声

动量累积历史梯度，能冲过平坦区和小坑；SGD 的噪声本身也是一种逃离机制。

症状损失来回震荡

学习率过大，或各方向曲率差异太大（等高线很扁）——在陡的方向上来回弹。

对策衰减 / 自适应步长

学习率衰减、warmup、Adam 的逐参数二阶矩估计，都是在给"陡方向"自动踩刹车。

症状前期几乎不动

梯度消失：深层网络里连乘的小导数让信号衰减到零（sigmoid 尤其明显）。

对策ReLU / 归一化 / 残差

换激活函数、加 BatchNorm/LayerNorm、用残差连接让梯度有短路可走。

一句话 所有"改进版优化器"（Momentum、RMSProp、Adam）都只是在回答同一个问题： 这一步的大小和方向，该怎么比朴素梯度下降估得更准一点。
08

全景回顾

把一次参数更新拆到不能再拆，就是这四步：

1
前向算出损失
输入一批数据，走完网络，得到预测，再用损失函数算出 L
2
反向求出梯度
链式法则从输出往回，得到每个参数的 ∂L/∂w
3
沿负梯度走一步
w ← w − η·∇L，步长由学习率决定
4
换一批数据，重复
一个 epoch 走完所有数据，几十上百个 epoch 之后收敛

公式速查

更新规则w ← w − η·∇L(w)
一维导数f'(w) = limh→0 [f(w+h) − f(w)] / h
梯度∇L = [∂L/∂w1, …, ∂L/∂wn]
动量v ← βv + ∇L  ;  w ← w − ηv
Adam 步长w ← w − η·m̂ / (√v̂ + ε)
收敛条件‖∇L‖ → 0 且 η 足够小
