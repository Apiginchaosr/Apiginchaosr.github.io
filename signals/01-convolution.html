卷积：把两个函数叠在一起

它是信号与系统里出现频率最高的那个符号，也是 CNN 里那个"卷积层"的同一个词。 这一章不背公式，只把 翻转、平移、相乘、相加 这四个动作放到你能拖着看的位置上。

Convolution Impulse Response LTI
参考 3Blue1Brown · 那么……什么是卷积？ B 站 ↗
01

一句话：卷积是一次带权重的平均

先看离散版本。两个序列 x 和 h，卷积记作 y = x * h：

y[n] = Σk x[k] · h[n − k] 对每一个输出位置 n，把 x 的一个"翻过来并平移 n"的版本逐点相乘，再全部加起来。

注意 h[n−k] 里的那个减号 —— 它同时干了翻转和平移两件事。 很多人第一次学就卡在这里：为什么不是 h[k−n]，为什么不是直接乘？下一节把它画出来。

换个说法会更好懂：y[n] 是 x 在 n 附近的一段加权平均，权重由 h 决定。 h 长成一个平滑的钟形，卷积就是"模糊"；h 一边正一边负，卷积就是"找边缘"。

02

翻过来，滑过去

下面三个横条分别是：原始序列 x、翻转并平移后的 h、以及它们的逐点乘积。 拖动 n，看第三条的面积怎么变：

y[n] = Σ x[k]·h[n−k] y[0] = 0.00
n 2

把按钮点下去，就是把 h[n−k] 换成 h[n+k] —— 后者叫相关（correlation）， 长得几乎一样，但少了那个翻转。深度学习里说的"卷积"其实大多是相关，因为核是学出来的，翻不翻无所谓； 信号处理里必须翻，因为 h 有明确的物理含义（系统对冲激的响应）。

03

叠加：把输入拆成一串冲激

为什么卷积长这样？因为它来自一条更基本的假设：系统是线性的、时不变的（LTI）。 线性意味着"输入相加，输出也相加"；时不变意味着"输入晚来一会儿，输出也只是晚来一会儿、形状不变"。

于是任何输入都可以拆成一串冲激的叠加，而每个冲激的响应都是同一个 h 平移一下、缩放一下。 把它们加起来，就是卷积。

Superposition 已叠加 0 个
每个冲激都唤起一个平移后的 h
04

连续的情况：两个方波

连续卷积只是把求和换成积分，动作一模一样。两个宽度为 2 的方波卷在一起，结果是梯形： 重叠面积从 0 开始线性增长，到完全重合时达到最大，再线性减少。

y(t) = ∫ x(τ)h(t−τ)dτ y(2.00) = 2.00

05

图像上的卷积：3×3 的小窗口

图像是二维的，卷积核也变成二维。一个 3×3 的核滑过整张图，每个位置做九次乘加 —— 这就是卷积层在做的事。 换一个核，输出的意义完全变了：

2D convolution

边缘核一边正一边负，平坦区域相乘后抵消，只有灰度突变处才留下大值； 模糊核全是正的且和为一，等于对邻域取平均；锐化核是"原图减去模糊"，把边缘的相对强度放大。

06

卷积定理：时域卷，频域乘

这一条把下一章的傅里叶变换和这一章接上了：

F{x * h} = F{x} · F{h} 时域里的卷积，等于频域里的逐点相乘。反过来也成立：时域相乘 = 频域卷积。

这条性质的价值是工程性的：直接做卷积，一个长度 N 的信号要 N² 次乘法；转到频域相乘再转回来， 只要 N log N（FFT）。这就是为什么"滤波"在实现里几乎总是先 FFT、乘一个窗、再 IFFT。

它也给了一个看卷积的新角度：h 的频谱就是它对各个频率的放大倍数。 低通核的频谱在低频接近 1、高频接近 0，所以卷积之后就变模糊了 —— 一句话讲完了滤波器的全部设计。

07

小结

1
翻转
h[k] → h[−k]。这一步来自"现在的输出由过去的输入决定"。
2
平移
h[−k] → h[n−k]。求第 n 个输出，就把 h 滑到 n。
3
相乘再相加
逐点乘积的总和，就是 y[n]。
4
把它理解成滤波器
h 决定"保留什么频率"，卷积就是滤波。
离散卷积y[n] = Σk x[k]·h[n−k]
连续卷积y(t) = ∫ x(τ)·h(t−τ) dτ
二维（图像）y[i,j] = Σm,n x[i−m, j−n]·k[m,n]
卷积定理F{x*h} = F{x}·F{h}
与相关的关系相关 = 不翻转的卷积 = x[n+k] 对 h
